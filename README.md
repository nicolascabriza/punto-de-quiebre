# Punto de Quiebre

Página web para buscar un negocio de Google Maps (prioridad Paraguay), elegir la sucursal correcta y copiar el enlace directo para dejarle una reseña, listo para grabar en una etiqueta NFC.

- Página: https://nicolascabriza.github.io/punto-de-quiebre/
- Usa Places API (New) de Google. La clave va en `GOOGLE_API_KEY`, dentro de `index.html`, y debe estar restringida a este sitio.
